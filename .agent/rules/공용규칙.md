# 공용 규칙
이 작업공간의 규칙 원본은 저장소 루트의 `AGENTS.md` 다. 작업 전에 반드시 읽고 따른다. 응답은 한국어.
진행 상황은 `kb/진행/` (작업 줄 파일의 `상태:`·`다음:`), 스킬은 `.agents/skills/` (구버전 `.agent/skills/`).
시작할 때 `python -X utf8 tools/ai_harness.py start` 로 링크·인계를 확인한다.
훅 자동 실행 여부와 관계없이 종료 전 `python -X utf8 tools/ai_harness.py status` 로 미커밋·미푸시를 확인한다.
