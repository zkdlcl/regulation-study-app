## 원고 규칙

`01_국제인도법의_첫걸음.md`는 읽기용 원고다. 첫 줄은 `#` 제목, 이후에는 `##` 절 제목과 본문 문단만 둔다. 출처·검토 메모는 대응표로 분리한다. 첫 시범은 짧은 개요 한 절만 반복해서 늘리지 않고 제1장 1~4절을 연결했다. 제1장 5절의 루소 인용과 이후 절은 다음 묶음이다.

해설은 원문 인용과 구분해 표현한다. 시험상 용어는 교재 표현을 연결해 소개하고, 요건·예외·열거·한정어를 보존한다. 녹음에서는 장황한 조문 위치나 근거 목록을 읽지 않는다. 연도·날짜와 ICRC는 발음을 확인하기 쉽도록 한글로 풀어 적었다. 해설의 연결 문장을 법규 원문으로 인용하지 않는다.

## 재생·재생성

저장소 루트에서 다음 명령을 실행한다.

```powershell
python -X utf8 tools/tts_narration.py --dry
python -X utf8 tools/tts_narration.py
```

기본 출력은 `audio/.cache/ihl-preview/`의 `녹음용.txt`, `01.mp3`, `manifest.json`이다. MP3 생성 시 대본이 Edge TTS 서비스로 전송된다. 음성은 기존 보수 듣기와 같은 SunHi를 사용하며, 문단 사이에 쉼을 넣는다. `--dry`는 네트워크 없이 녹음용 글만 생성한다. `--script`와 `--out`으로 다른 대본과 출력 폴더를 지정할 수 있다. 다른 대본에는 같은 폴더에 번호가 같은 `NN_대응표.json`이 필요하다. 음성 조각은 기존 캐시 규칙을 재사용한다.

목차에는 네 절의 시작 시간이 들어간다. 이 미리듣기는 기존 앱 목차·보수 음원·학습 기록을 바꾸지 않는다. 원고를 수정한 뒤에는 다시 생성해야 하며, manifest의 `script_sha256`으로 생성 당시 원고를 확인할 수 있다.

## 시범 검증 결과

2026-11-05 생성본: 8분 14초, 네 절, 약 3MB. Chrome의 Web Audio로 MP3 전체를 디코딩한 길이는 494.21초이며, 네 절의 시작 이후 각각 20초 구간에 음성 신호가 있음을 확인했다. 목차 길이·구간 순서·원고 해시도 일치했다. 이는 파일·신호 검증이며 사람이 발음과 억양을 끝까지 청취한 결과는 아니다.

```powershell
python -X utf8 -m unittest discover -s tests -p tts_narration_test.py
node tests/tts_narration_audio_check.mjs
```

첫 명령은 5개 테스트로 본문 파싱, 비낭독 메모 차단, 대응표·전체 절 목록, 네트워크 없는 dry 실행을 확인한다. 둘째는 음원 생성 후 실행하며 로컬 Chrome과 `tests`의 Puppeteer 의존성을 사용한다. 기존 보수 생성기의 `--dry` 실행도 확인했다. 시범 단계이므로 앱 빌드·게시 검증은 아직 대상이 아니다.
