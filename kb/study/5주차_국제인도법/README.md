# 5주차 국제인도법 — 2026-11-12

8명 × 7문항 = 56문항. 실제 시험 기출과 구분한 스터디 묶음 `st5`로 수록한다.

- `공식답지_원본.md`, `내답_원본.md`: 첨부 파일 그대로 보관. 내장 그림 데이터도 보존.
- `문항.json`: 정답이 지문에서 드러나지 않도록 문제·보기와 해설을 분리한 데이터.
- `내답.json`: 최초 답·출제자 답·원문 블록. 확신도는 미제공이므로 null.
- `문화재표장.png`: 문제 원본에 내장된 그림. 전권능 5번 지문에 표시.
- 앱 입력: `kb/study/답지.json`의 `add`, 출처 묶음 `st5`.
- 재생성: `python -X utf8 tools/import_study5.py --apply`. 원본 MD를 우선 사용하므로 다른 컴퓨터에서도 재현 가능.

Google Docs: https://docs.google.com/document/d/1IeWPKv9kcMsUbfHO0MMz8R7frtluZxV0c9xhW7PrE5I/edit?tab=t.x0wknxnqieue
링크를 다시 가져온 자료가 아니라 사용자가 첨부한 두 MD를 기준으로 전사했다.

## 답지 대조 시 주의

- 최강락 7번: 해설이 ③과 ④를 모두 틀린 보기로 지목하므로 `③,④`로 수록.
- 전권능 5번: 공식 O와 그림을 보존. 교재는 청색·흰색 방패를 1954년 협약 설명에 제시하므로 문제의 ‘제2의정서’ 표현은 출제자 확인 대상.
- 신승현 7번: 공식 ② 보존. 문제 파일과 답지의 평가 조건·⑤ 보기 표현 차이가 있다. 군사적 이익이 크다는 사실만으로 모든 공격의 적법성을 일반화하지 않도록 교재 관련 원문과 메모를 함께 표시.
- 박준규 5번: 공식 X는 특별 보호 대상 목록 기준. 교육시설에 대한 일반적인 민간 물자 보호까지 부정하지 않는다.
- 원문 인용은 저장소 교재에서 가져와 문자열 존재 검사를 거친다. 출제자 해설 전체에 대한 독립적인 법적 검증을 마쳤다는 의미는 아니다.

운영 `state/progress`, `backup/progress.json`, 오답 큐를 덮어쓰지 않는다. 최초 답은 해설에서 표시하며 기존 풀이 기록에 seed하지 않는다.

## Claude 게시 인계

검증: 빌드·답지 검사, 브라우저 테스트 37개 통과. 태블릿 가로·세로·폰 라이트/다크 총 6화면 확인. 원본 2개 해시 일치와 기존 답지 데이터 불변 확인. 최초 전체 검사에서 별도 포트 미준비 3개는 서버 준비 후, 묶음 수 기대값 1개는 5주차 추가에 맞춰 수정 후 각각 재검사 통과했다.

`AGENTS.md` 및 `artifact-release` 스킬을 읽고 최신 main에서 게시한다. 게시본과 dist의 diff를 먼저 확인하고, 검증된 `orgmaster.html`을 게시한 뒤 운영 학습 기록은 읽어서 백업만 한다. dist·게시 버전·작업 줄을 갱신하고 커밋·pull --rebase·push까지 마친다. 56문항, 복수정답, 문화재 그림, 최초 답 표시를 게시 후 확인한다.
