# 진행 상황 (병렬 세션용)

여러 터미널·에이전트(Claude·Codex·Gemini 등)가 동시에 일해도 서로 지우지 않도록 나눠 둔다.

- **작업 줄 파일** `kb/진행/<줄>.md` — 줄마다 하나. 맨 위 `상태:`·`다음:` 두 줄이 인계의 핵심. 자기 줄 파일만 고친다(Edit). 새 일이면 새 파일.
- **메모 로그** `kb/진행/메모.log` — 덧붙이기만 한다. `python -X utf8 tools/kbq.py checkpoint --줄 <줄> "<한 일·다음 한 줄>"`
- 통째 덮어쓰기(Write)는 훅이 막는다. 끝난 줄은 `상태: 완료` 로 바꾼다(지우지 않음).
- 세션 시작 때 훅이 각 줄의 상태·다음과 최근 메모를 넣어 준다.
- 오래된 지식(작업 요령·게시 기록·사고 기록)은 `kb/진행상황.md`.
